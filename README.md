# Sistema de Escala Militar 🎖️

Este projeto marca um ponto de virada na administração 
de escalas de serviço. Anteriormente, o processo era dependente de planilhas manuais, 
o que gerava descentralização da informação, 
dificuldade de acesso e riscos de redundância ou erros humanos.
